# Enterprise Architecture Glossary

| Term | Technical Definition |
| :--- | :--- |
| **Air-Gap** | A physical or logical network security measure ensuring that an isolated computer network has zero direct connection to external public networks or the internet. |
| **Attack Surface** | The total sum of vulnerabilities, open ports, exposed services, and network paths across an organization that an unauthorized user could attempt to exploit. |
| **BM25** | Best Matching 25; a probabilistic text retrieval algorithm used in information retrieval and hybrid search to score document relevance based on term frequency and document length. |
| **CEA Guidelines** | Central Electricity Authority regulations in India governing cyber security in the power sector, mandating strict localization and isolation of critical operational data. |
| **CVE** | Common Vulnerabilities and Exposures; a publicly disclosed computer security flaw cataloged by MITRE and the National Vulnerability Database (NVD). |
| **CVSS** | Common Vulnerability Scoring System; an open industry standard for assessing the technical severity of software vulnerabilities on a scale from 0.0 to 10.0. |
| **DPDP Act 2023** | The Digital Personal Data Protection Act of India, establishing statutory obligations for data fiduciaries regarding data processing, localization, and user rights. |
| **Decision Support** | A technical system that analyzes operational data and presents structured, explainable recommendations to human decision-makers without executing autonomous actions. |
| **Explainable AI (XAI)** | AI architectures that provide explicit causal attribution, data citations, and score breakdowns for every generated output rather than acting as a black box. |
| **Purdue Model (ISA-95)** | A reference architecture for industrial control systems (ICS) that segments networks into hierarchical security levels from physical sensors (Level 0) to enterprise IT (Level 4/5). |
| **RAG** | Retrieval-Augmented Generation; a technique that optimizes the output of a language model by referencing an authoritative external knowledge base before generating a response. |
| **SCADA** | Supervisory Control and Data Acquisition; an industrial automation control system architecture used to monitor and manage electrical grids, substations, and utility assets. |
| **Zero Egress** | An architectural state wherein zero bytes of outbound network traffic exit the designated private enterprise subnet or virtual machine boundary. |
| **Zeroization** | The cryptographic or physical erasure of sensitive data, keys, or in-memory context buffers by overwriting storage registers with predetermined bit patterns. |
